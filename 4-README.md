# Proof

Turn one sentence into a company you can prove.

A browser-based MVP of the complete seven-step, evidence-gated founder journey:

1. Sharpen the idea
2. Find the big version
3. Try to kill it
4. Prove demand
5. Build the smallest thing
6. Land first customers
7. Pitch with proof

Proof Score is weighted toward real-world evidence, not generated output. Projects persist locally in the browser. The contextual coach uses deterministic, project-aware guidance in this MVP and does not pretend to be connected to a model or backend.

## Run locally

Open `index.html` directly, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
